# 10. Открытые вопросы для владельца проекта

Здесь только то, что спецификация не может решить сама. Всё остальное решено и обосновано в `00_overview.md` §6 и профильных файлах. До ответа исполнители используют рекомендацию.

| ID | Вопрос | Почему нужен ответ | Рекомендация | Где влияет |
|---|---|---|---|---|
| Q1 | Путь Go-модуля и расположение репозитория на GitHub | Путь модуля попадает во все импорты; менять потом — массовая замена | `github.com/<ваш-GitHub-логин>/tenant-backoffice/backend` (модуль в подкаталоге `backend/`). До ответа M1.1 использует этот шаблон с логином из `git remote get-url origin`, а без remote — временный `tenant-backoffice/backend` с записью в отчёт | M1.1, все импорты |
| Q2 | Держатель авторских прав в `LICENSE` (MIT требует строку `Copyright (c) <year> <holder>`) | Правило проекта — не упоминать людей в репозитории, но MIT без держателя некорректна | GitHub-логин (тот же, что в Q1) вместо полного имени: `Copyright (c) 2026 <login>` | M6.4 |
| Q3 | Язык README и сообщений в репозитории | Спека на русском, а публичный репозиторий читают на английском | README, код, комментарии, тексты UI и ошибок API — на английском; спека остаётся в `docs/spec` на русском (уже зафиксировано в правилах задач `09`); при желании короткий `README.ru.md` | M6.4, все задачи |

Решено без вопросов (для справки, чтобы не поднимать повторно): типы узлов и глубина (Р-01), схема иерархии (Р-02), RLS и передача актора (Р-13), 404 против 403 (Р-11), идемпотентность (Р-14), одна валюта и BIGINT (Р-05, Р-07), Postgres 18 вместо 19 (`00` §3.2), TypeScript 6.0 вместо 7.0 из-за пиров `typescript-eslint` (`00` §3.3), e2e вне `make ci`, но обязательное задание CI (`08` §5), UI без shadcn/ui (Р-15).
