## Deviations from `03_api.md` and domain enums (OpenAPI now wins; `03` to be updated)
1. `ErrorCode` also contains `invalid_node_type`, `invalid_name`, `invalid_email`, `invalid_role` (apperr field-level codes used in `errors[].code`, e.g. the `invalid_name` example in `03` section 2.1) and `invalid_password` (named in `03` section 5.1 but absent from the 2.3 table). Add them to the table.
2. apperr lacks the transport codes `token_missing`, `invalid_cursor`, `invalid_period`, `payload_too_large`, `unsupported_media_type`, `rate_limited`, `internal` (M4.2 adds them); the test accepts them because they are in the `03` table.
3. `SettingItem.sourceNodeId` is nullable (null = built-in default; `03` does not say what a default at the root returns). `own` is nullable.
4. Setting path parameter `key` is a plain string, not the `SettingKey` enum, because an unknown key must give 404 `unknown_setting`, not a 400 from an enum check. `SettingKey` enum is used in response bodies.
5. `granularity` is optional with default `day` (`03`/`05` do not give a default). `from`/`to` of reports are required `date`.
6. Pattern `MoneyAmount` allows up to 19 digits (a superset of MaxInt64; the exact bound is `invalid_amount` in the domain).
7. `CreateNodeRequest.type` is the full `NodeType` enum including `platform` (the domain gives 422 `invalid_parent_type` for it, as `03` says).
8. Login `password` has `minLength 1, maxLength 128` (no min 12, so a short wrong password is `invalid_credentials`, not a validation error).
9. Response `before`/`after` of audit are `object` of string values, nullable (`audit.Fields` is key/value strings). `Transfer` has properties `in`/`out`. `DELETE /nodes/{id}/settings/{key}` returns `SettingItem` (03 says only "200").
10. `balance`/`amount` of the balance and operations are `MoneyAmount`; in report children `balance` is `ReportSum` (as `report.Sum`).
11. `count`, `expiresIn`, `childrenCount`, `limit`, `status`, `Retry-After` are the only `integer` fields (checked by the test). `SettingValue` is `oneOf string|boolean` (generated as a union type).
No other mismatches between enums/limits and the domain: the test compares them against the domain packages and passes.
