- `usecase/port/audit.go`: `AuditEntry` got `TargetID uuid.UUID` (the table has `target_id uuid NOT NULL`); `AuditWriter` kept; new `AuditRepo` (`List(ctx, tx, AuditFilter, *AuditCursor, limit) []AuditRecord`), `AuditFilter`, `AuditCursor`, `AuditRecord` (entry plus `ActorEmail`, `NodeName`, as `03` GET /audit shows). `NopAudit` removed (it had no other users).
- `adapter/postgres/audit_repo.go`:
  - `AuditWriter` (`NewAuditWriter(log, clock, ids)`) inserts through the `tx` it is given (never the pool), so the entry commits and rolls back with the change (EC-96). It builds the record with `audit.NewEntry` (secret-looking keys, unknown actions and empty ids are refused with `validation_failed`), sorts map keys to ordered `Fields`, writes `before`/`after` as jsonb (SQL NULL for none), and skips an entry whose snapshots are equal (second barrier for EC-101).
  - `AuditRepo` (`NewAuditRepo(log)`): one query, `audit_log JOIN nodes ON path <@ scope.path`, `LEFT JOIN users` for the e-mail; filters node, action, actor, `from` (inclusive), `to` (exclusive); keyset `(occurred_at, id) < cursor` with `ORDER BY occurred_at DESC, id DESC`. Visibility is the RLS of `audit_log` and `nodes`; no SECURITY DEFINER, no policy touched.
- `usecase/audit/list.go`: UC-AU1 `ListAudit` (`Validate`: scope required, known action, `from < to`, limit 1..200, cursor; `authz.Require(audit.read, scope)` first, so a hidden scope is `not_found` and a viewer is `forbidden`; read-only transaction; one extra row decides `NextCursor`; opaque cursor = base64 of microseconds and id).

All writes now carry `TargetID` (node id; for `node.deleted` the deleted node on the parent; for member actions the user id; for the three move entries the moved node). Move: `child_moved_out` and `child_moved_in` now carry `node_id` and `name` (before, the spec asked for the name; M2.5 had only `node_id`); neither carries the other parent. Self-removal still writes `member.revoked` before the DELETE. Refusals and no-ops write nothing (existing early returns; now tested with the real writer).
