## Interface for M5.4
```tsx
import { MoveNodeDialog, useMoveNodeDialog } from '@/features/tree'; // features may not import each other: wire it in the route, or via props/children
const dialog = useMoveNodeDialog();           // { isOpen, show(), close() }
<button onClick={dialog.show}>Move</button>
<MoveNodeDialog nodeId={id} open={dialog.isOpen} onClose={dialog.close} />
```
`onClose` fires on Cancel, Escape and after a successful move. The body mounts only while `open`, so each opening starts clean. Needs the router context (`useRouter().options.context.api`). Note: `features/node` cannot import `features/tree` (layer rule); the route file `nodes.$nodeId.index.tsx` may render the dialog and pass the open handler to the node feature. Also exported: `NodeTree`, `NodeName`, `nodeIdFromPath`.
