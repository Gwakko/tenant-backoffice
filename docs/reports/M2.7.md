## Deviations
1. T-ISO-17: spec text says a cursor of scope A1 used for A2 gives 400 `invalid_cursor`. The existing node and member cursors are bound to nothing; they only say "after (name key, id)", and the scope is decided again on every page by the Checker and RLS. The test checks the isolation property that matters: a cursor of B used on B by A -> `not_found`, same value as for a missing parent; a cursor of B (positioned inside A's name range) used on A's lists shows only A's nodes (non-vacuous: the page is not empty); the same for move targets and members; a malformed cursor gives the same `validation_failed` to every actor. The strict `invalid_cursor` stays for the operation and audit lists (M4). Mutation (g) proves the test sees the property.
2. The spec calls the viewer `viewerA`; the fixture keeps `ViewerA1u1` (a viewer on A1u1, already used by the old tests); `AnalystA` was added (analyst on A1). `viewerA` on A is not added: it would change the expected sets of the old tests.
3. T-ISO-03 has 6 operations, not 7 (settings: M3.5). T-ISO-09 and T-ISO-18 call use cases, not HTTP.
4. The snapshot is now computed over all tables of the schema, not four fixed ones.
