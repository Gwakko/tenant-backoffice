## Allow-list and reasons
- errors: sentinel errors; fmt: error wrapping (reserved); strings: name normalization; strconv: number parsing (reserved); unicode, unicode/utf8: character classes and rune limits; time: values passed as arguments, no time.Now; sort, slices, maps, cmp: deterministic ordering and helpers (reserved); math: overflow bounds for money.Amount (reserved).
- github.com/google/uuid: identifier type; x/text/cases and x/text/unicode/norm: name folding and normalization.
- internal/domain/**: sub-packages may import each other.
