## Container ownership (root-owned files)
The CI job runs with `GO=` on the host, no containers, so no root-owned files. Locally `make ci` writes only to Docker volumes (`gomod`, `gobuild`), not into the repo. `make -C /workspace` in go-tools runs as root; `migrate-roundtrip` and tests create no repo files. `make` uses only portable commands (no `sed -i`, no `timeout`).
