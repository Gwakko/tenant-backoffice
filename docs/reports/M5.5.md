# Отчёт M5.5: история операций, отчёт, аудит

## Сделано

- Маршруты `web/src/routes/nodes.$nodeId.{operations,reports,audit}.tsx` (`validateSearch` через Zod, смена фильтров = новая запись истории, поэтому «назад» восстанавливает фильтры). Табы в `nodes.$nodeId.tsx`: Operations всегда, Reports только при `report.read`, Audit только при `audit.read` (права через `usePerms`, экспортирован из `features/node`). `routes/index.tsx`: текст заменён на «Select a node in the tree.».

- `features/audit`: infinite `['audit', scope, filters]`, фильтры действие и период в URL, время, действие (читаемое имя, словарь исчерпывающий), актор (`Hidden user`, если email нет), узел, цель, `before/after` в `<pre>` (значения и общий текст обрезаются, только текст).
- `features/reports`: `['report-summary', ...]`, `['report-children', ...]` (infinite, курсор); форма RHF+Zod (from/to/tz/granularity), проверка периода на клиенте теми же правилами, что сервер (`invalid_period`, ≤ 366 дней, `from < to`, реальные даты); tz по умолчанию: URL, затем эффективная `display_timezone` узла, затем пояс браузера (список `Intl.supportedValuesOf`); итоги, ряд таблицей и SVG-графиком (`role="img"`, `aria-label`, таблица как текстовая альтернатива); суммы через `BigInt`, высоты столбцов тоже через `BigInt`.
- Общее: `lib/{dates,list,text,timezones,searchParams}.ts`, `hooks/QueryProblem.tsx` (403 перезапрашивает `['perms', id]`, 429 с `Retry-After`, сеть/5xx кнопка Retry), `hooks/useCursorReset.ts` (`invalid_cursor` при подгрузке страницы: `resetQueries`, список грузится с первой страницы), `components/ui/Table.tsx`, `test/lists.ts`. `routeTree.gen.ts` перегенерирован плагином.
- Эндпоинты по контракту `openapi.yaml`: `GET /operations` и `GET /audit` с `scopeNodeId` (в задаче были пути `/nodes/{id}/operations`, `/audit`; в API их нет), `scopeNodeId` и id отчётов всегда из маршрута.
- Тесты: 205 (было 161): `operations.test.tsx` (12), `audit.test.tsx` (6), `reports.test.tsx` (13), `format.test.ts` (3), `lib/dates.test.ts`, `node/layout.test.tsx` (4, в нём T-W-02 в сценарии «доступ отозван при открытой странице»: `['me']` перечитывается именно экраном 404).
