# Report M1.2: Docker Compose, Dockerfiles, Makefile, DB roles

## Done
- `compose.yaml`: `postgres` (healthcheck `pg_isready`), `api` (healthcheck via `/api healthcheck`), `web` (nginx placeholder, `/api/` proxied to `api`, healthcheck), `go-tools` and `web-tools` (profile `tools`), `playwright` (profile `e2e`). Published ports are configurable: `TB_POSTGRES_HOST_PORT`, `TB_API_HOST_PORT`, `TB_WEB_HOST_PORT`; DB address from `TB_DB_HOST`/`TB_DB_PORT`; all bound to 127.0.0.1. No secrets: passwords are required from `.env` (`${VAR:?}`).
- `docker/api.Dockerfile` (alpine build, distroless static nonroot), `docker/go-tools.Dockerfile` (golang bookworm, golangci-lint v2.15.0 via `go install`, make, psql client), `docker/nginx.conf`.
- `backend/db/bootstrap/roles.sql`: idempotent (`format(...) \gexec`), passwords and db name from psql variables; creates `tb_owner`, `tb_app` (LOGIN, NOSUPERUSER, NOBYPASSRLS, NOCREATEDB, NOCREATEROLE), database owned by `tb_owner`, CONNECT for `tb_app` only, default privileges for tables, sequences, functions.
- `Makefile`: `GO`, `NPM`, `PSQL` overridable (CI: `GO= NPM= PSQL="psql -h 127.0.0.1"`); targets `up down logs db-bootstrap keys lint lint-go test-unit check-hosts ci ci-inner ci-go ci-web` real; `migrate seed gen gen-check test-int test-iso test-api migrate-roundtrip ec-check lint-web typecheck build` print `not implemented yet` and exit 1; `test-web e2e e2e-inner` print it and exit 0. `.env` is created from `.env.example` automatically. No `sed -i`, no `timeout`.
- `make keys`: `keys/<kid>.pem` (openssl ed25519) and `keys/cursor.env` with `TB_CURSOR_KEY` (loaded by compose `env_file` and Makefile).
- `.env.example`, root `.gitignore` (`/.env`, `/keys/`).
- `backend/cmd/api/main.go`: added `healthcheck` subcommand (see deviations).

## Deviations
- Distroless has no shell/curl/wget, so the api container healthcheck needs the binary itself: added `api healthcheck` (GET `/healthz` on `TB_HTTP_ADDR`, host defaults to 127.0.0.1). Not in the M1.2 file list; small, linted.
- `golangci-lint` is built with `go install` in go-tools (not the prebuilt image binary) so it is compiled with Go 1.27.3 matching the project's `go` directive.
- nginx proxies `/api/` with the path kept as is (no prefix stripping) and resolves `api` per request via Docker DNS (`127.0.0.11`), because static upstream resolution failed when `api` was not yet resolvable at nginx start.
- Postgres 18 image: data volume is mounted at `/var/lib/postgresql` (path changed in 18).
- Playwright image tag: spec 00 §3.3 says `v1.65.1-noble`; it exists, used as is (not pulled, manifest only).
